# StudyLoop Design System

## Brand direction
A gender-neutral, calm and refined study workspace built around warm neutrals and deep slate.

## Colour palette
- Cream background: `#EDE3D3`
- Warm taupe: `#78665A`
- Deep slate: `#373640`
- Light surfaces: `#F7F1E8`
- Dark surfaces: `#42414B`
- Dark-mode text: `#F0E8DC`

## Themes
- Light mode uses cream page backgrounds, warm off-white cards, taupe actions and dark text.
- Dark mode uses deep slate page backgrounds, slightly lighter slate surfaces, cream text and muted taupe accents.
- The theme toggle is available in the top bar and the selected theme is saved in local storage.

## Typography
- Playfair Display for headings and brand moments.
- Inter for body text, labels, forms and navigation.

## Reusable UI components
Sidebar navigation, top header, section title, stat card, subject card, task row, status badge, progress bar, flashcard, buttons, form inputs and empty state.
