# StudyLoop
A student study-planning and revision MVP built with Next.js, React and JavaScript.

## Inspiration
Inspired by the spaced-repetition learning concept used by CleverDeck, listed in Y Combinator's Education directory. StudyLoop is an independent student-focused implementation; it is not a copy of CleverDeck.

## MVP features
- Dashboard overview
- Subject management (add subjects)
- Flashcards (create, reveal answers, navigate cards)
- Study planner (add and complete tasks)
- Progress overview
- Shared application state using React Context
- Responsive layout and realistic mock data
- Subject deletion
- Flashcard ratings
- Revision tracking

## Tech Stack

- **Framework:** Next.js (App Router)
- **Frontend:** React and JavaScript
- **Styling:** CSS
- **State Management:** React Context API
- **Data Persistence:** Browser localStorage

No backend or external APIs are used. Application data is managed using React Context and persisted in the browser's localStorage.

## Run locally

1. Install Node.js (LTS).
2. Clone this repository.
3. Open the project folder in VS Code.
4. Open Terminal and run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal (usually http://localhost:3000).
