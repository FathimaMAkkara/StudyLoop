# StudyLoop
A student study-planning and revision MVP built with Next.js, React and JavaScript.

## Inspiration
Inspired by the spaced-repetition learning concept used by CleverDeck, listed in Y Combinator's Education directory. StudyLoop is an independent student-focused implementation; it is not a copy of CleverDeck.

## MVP features
- Dashboard overview
- Subject management (add subjects)
- Flashcards (create, reveal answers, navigate cards)
- Study planner (add and complete tasks)
- Progress overview
- Shared application state using React Context
- Responsive layout and realistic mock data

## Tech stack
Next.js App Router, React, JavaScript, CSS and React Context. No backend or external API is used; data is held in client-side React state and resets on refresh.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.
