
# StudyLoop – Project Plan

## Project Overview
StudyLoop is a student study-planning and revision workspace built using Next.js, React and JavaScript.

## Task Distribution

| Team Member     | Responsibilities |

| Fathima Muneer  | Initial project setup, product assumptions, dashboard, subject management, README and GitHub integration |
| Khadija Haniyya | Flashcard functionality, flashcard ratings, revision tracking and related application updates |
| Both Members    | Study planner, progress tracking, testing and final presentation |

## Development Workflow
- The project was developed collaboratively using Git and GitHub.
- Separate feature branches were used for development.
- Pull requests were reviewed and merged into the main branch.
- Both members contributed to the shared repository.

## Project Status
The StudyLoop frontend MVP has been implemented with dashboard, subject management, flashcards, study planner and progress tracking features.
